# Sesi AI Agent: UI/UX Stylist (Conversation 4)

1. Baca dan ikuti panduan peran lengkap di [ai-agents/UI-UX-Stylist.md](../../../ai-agents/UI-UX-Stylist.md), aturan bersama di [AGENTS.md](../../../AGENTS.md), serta hub proyek di [DEV_SYNC.md](../../../DEV_SYNC.md).
2. Rapikan tampilan antarmuka tanpa merusak logika backend, cek dengan `typecheck` & `lint`, dan catat di `DEV_SYNC.md` Bagian 3.
3. Jelaskan perubahan layar menggunakan **Bahasa Indonesia sederhana yang ramah pemula** (jangan gunakan gaya bahasa teknis).
4. Jika masih perlu perbaikan data atau pengecekan lanjutan oleh AI Agent lain, wajib sertakan blok **`Prompt untuk AI Agent Selanjutnya`** yang siap disalin.
